常见问题

你可能想问

需要先装 Python、ffmpeg 吗？

不需要。双击启动脚本后，它会自动检查环境，把缺少的 Python、ffmpeg、语音识别等组件下载到程序文件夹里（中国大陆会自动使用国内镜像加速），不需要管理员权限，也不会改动系统。以后有更新，重新下载覆盖即可，脚本会自动补装新依赖。

怎么卸载？

直接删除 AutoStudio 文件夹即可。你的设置和对话记录保存在用户目录下的 .autostudio 文件夹里，不需要的话也可以一起删掉。

真的免费吗？

AutoStudio 本身完全免费开源。你需要自备大模型：用 ChatGPT 订阅登录就不额外花钱；用 API Key 则按服务商价格计费，也可以用 Ollama 跑本地模型完全免费。

需要什么样的电脑？

普通 Windows / macOS / Linux 电脑即可。语音识别在 CPU 上也能跑，有 NVIDIA 显卡会更快（没装 CUDA 会自动用 CPU）。

AI 真的能“看懂”视频吗？

主流大模型只接收图片，所以 AutoStudio 会把视频拆成镜头、分析运动和声音、转写台词，再把带时间戳的连续画面交给模型；遇到拿不准的地方还会逐帧细看。配置 Gemini 后还能用原生视频理解。

配音能用哪些声音？

内置 12 种热门风格音色（Edge 神经语音），也可以接入火山引擎豆包语音（剪映同款音色）、本地 GPT-SoVITS 声音克隆，或任意 OpenAI 兼容的 TTS 接口。注意：Edge 免费语音自 2026 年 10 月起在部分地区不可用，可通过代理或其它引擎替代。请只克隆你有权使用的声音。

定时任务需要一直开着电脑吗？

需要 AutoStudio 在运行。可以设置开机自启；错过 1 小时以内的任务会在恢复后自动补跑。

“ChatGPT 订阅登录”是官方支持的吗？

它使用与 OpenAI 开源的 Codex CLI 相同的登录流程，调用的是 ChatGPT 的 Codex 后端，并非公开文档化的 API，可能随 OpenAI 调整而变化。请仅用于你自己的账户并遵守 OpenAI 使用条款。AutoStudio 与 OpenAI 无关联。
